# 网站功能与内容维护

## 功能结构

| 位置 | 访客可以做什么 | 内容来源 |
| --- | --- | --- |
| 首页个人介绍 | 了解创作者、进入内容目录或成长记录 | `components/Hero.tsx`、`data/site.ts` |
| 首页内容导航 | 查看四个方向、入口数量，进入专区 | `data/sections.ts` |
| 首页精选创作 | 打开 3 篇 B 站视频 | 构建期聚合 → 本地视频缓存 → 精选降级数据 |
| B 站成长里程碑 | 切换日期节点、查看当时的播放成就和账号指标 | `data/milestones.ts` |
| 时间手记 | 查看北京时间的年、月、周进度 | 客户端日期，每分钟刷新 |
| Apple 专区 | 查找 Apple Watch、Apple TV 与 iOS 资源 | `data/sections.ts` |
| 教程与文档 | 下载资料包、打开文档或资源订阅 | `data/tutorials.ts` → `data/sections.ts` |
| 资源收藏 | 进入网盘、博客、WebWord，展开每日一图 | `data/sections.ts`、`DailyImage` |
| 数字实验室 | 打开工具实验、查看公开项目 | `data/sections.ts`、GitHub 构建期聚合 |
| 社区联系 | 进入 Telegram 频道、群聊，展开 QQ 群号 | `data/site.ts`、`Community` |

## 调整专区内容

在 `data/sections.ts` 修改对应专区的介绍、标签、分类和链接。首页入口卡片、入口数量及专区页面复用该数据，避免分别维护。入口数量统计当前专区列出的资源项；不同专区可引用同一项，不应将各专区数量相加并宣称为去重后的全站资源数。

教程资源保存在 `data/tutorials.ts`，按现有来源标签分组。新增来源标签时，应同时更新 `sections.ts` 的分类规则，避免资源未被收录。实验室的 GitHub 仓库和每日一图属于附加内容，不计入「精选入口」数量。

搜索只匹配当前专区的资源标题、描述和来源标签，不请求远端服务、不保存关键词。匹配时展开所有有结果的分类，无结果时展示恢复按钮。各分类仍可通过 URL 锚点直接访问，例如 `/apple/#ios`。GitHub 聚合项目不属于资源搜索范围。

## 维护成长里程碑

节点按日期从早到晚排列，组件默认选中数组最后一项。日期使用 `YYYY-MM-DD`，界面以 `YYYY.MM.DD` 展示。每项包含稳定 `id`、日期、类型、标题、说明、指标、数据备注、标签和相关链接。

已录入站主提供的记录：

| 日期 | 事件 | 数据口径 |
| --- | --- | --- |
| 2022-06-15 | 稿件达到 1 千播放 | 稿件播放成就 |
| 2022-11-09 | 10 位粉丝 | 当日账号粉丝数 |
| 2023-07-13 | 1 千位粉丝 | 当日账号粉丝数 |
| 2025-08-02 | 稿件达到 50 万播放 | 稿件播放成就 |
| 2026-02-04 | 成为 UP 主 6 周年；累计 134 个作品、1,239 位粉丝 | 截至该日期的历史数据 |

稿件成就不可改写为账号累计播放量。六周年的作品数、粉丝数不可标成实时统计。当前未提供成就稿件的具体链接，所以节点统一链接到 B 站个人主页；获得真实稿件地址后可修改对应 `link`。只添加已确认的经历，不自动推断首次投稿、粉丝增长原因或其他平台的成就。

时间线使用可访问的纵向标签页：点击切换；上下/左右方向键循环选择；Home/End 跳到首尾；Tab 进入当前详情和链接。移动端使用上下布局，无需横向滚动。

## 架构与验证

Next.js App Router 负责页面组装，`ZonePage` 统一专区布局。交互限定在 `Shell`、`ResourceDirectory`、`Milestones`、`TimeProgress` 和 `DailyImage`；无需新增后端、数据库或环境变量。

B 站视频、GitHub 项目在构建时聚合，失败时使用现有缓存或本地内容。成长里程碑始终读取本地确认的数据。浏览器只在展开每日一图后请求图片；图片失败时提供 Bing 入口。

运行 `npm run typecheck` 和 `npm run build` 检查类型及静态导出。用 HTTP 服务预览 `out/`，重点检查：

- 首页四个专区链接与数量一致；各专区搜索、无结果、清空和分类锚点正常。
- 五个里程碑的日期、数值、指标口径正确，鼠标与键盘均可切换。
- 手机导航能打开、跳转后关闭，Escape 关闭并返回菜单按钮焦点。
- 年度进度展示，北京时间周/月明细和 QQ 群号可展开。
- 桌面与窄屏没有横向溢出；浏览器没有应用错误。

保留现有 Vercel 与静态导出方式。代码修改不等于线上部署，发布前以最终 `out/` 为准。
